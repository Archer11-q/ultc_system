# 高校实验室实训耗材智能管理系统

基于 C 语言开发的高校实验室实训耗材管理系统。完整覆盖耗材入库、学生领用、归还、损耗报废、库存预警、实训消耗统计、耗材检索全流程。

## 编译运行

### 环境要求

- CMake ≥ 3.16
- GCC ≥ 9（C11 标准）或 MSVC
- 操作系统：Windows / Linux

### 编译

```bash
# 在项目根目录下
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

### 运行

```bash
./build/ultc_system
```

首次运行自动创建默认管理员账号：`admin` / `admin123`

### 运行测试

```bash
# 全部测试
./build/test_file_io
./build/test_auth
./build/test_material
./build/test_borrow
./build/test_inventory

./build/test_stats

```

## 技术特点

- **纯 C11 标准**：无 C++ 依赖，零第三方库
- **链表动态存储**：所有集合使用单向链表，无固定数组容量限制
- **二进制文件持久化**：统一 `魔数+版本+条数+数据体` 格式，大端序跨平台
- **跨平台兼容**：`#ifdef _WIN32` 条件编译，同一份源码 Windows/Linux 均可编译
- **UTF-8 编码**：源码 + 控制台 + CSV 导出全链路 UTF-8
